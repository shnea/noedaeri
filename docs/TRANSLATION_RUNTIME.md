# 문장 번역 실행 기록

기준일: 2026-10-10. 새 모델 없이 기존 n8n AI Job·공통 자원 예약을 재사용한다.
한국어·영어·일본어·중국어·스페인어·프랑스어·독일어, 원문 자동 감지를 제공한다.
원문 요청당 4,000자, 번역문 80,000자 이내로 검증한다. 실제 감지 언어 필드는 없다.

## 설치·연결

기존 n8n 연결·모델 공급자 설정이 필요하다. 설정은 SOPS + age 암호화 env를 사용한다.
`scripts/apply_n8n_compute.py --translation`은 읽기 전용 준비이며 기존 분기·프롬프트·
연결·자격증명을 보존한다. `--apply --translation`은 번역 분기와 전용 지침 노드를 추가한다.
공통 준비 플래그를 끄고 작업을 비운 뒤 적용해야 한다. 버전 충돌·실행 중 워크플로를 거부한다.
서버 export 원본은 Git 제외 경로에 0600 백업하고 비밀값을 출력하지 않는다.
재적용은 동일 지침이면 멱등이고 다른 번역 노드가 있으면 덮어쓰지 않고 거부한다.

운영에서는 실행 작업이 없는지 확인하고 API·워커를 정지한 뒤 준비 플래그 0으로 적용,
기존 워크플로 보존·저장·활성화를 확인하고 암호화 설정을 1로 복원하여 재시작했다.
실제 한국어→영어 문장 번역·중복 요청 재사용·공통 작업 조회·TXT 수령을 확인했다.
실제 응답의 공급자는 google, 모델은 gemini-3.5-flash-lite였다. 모델 고정 계약은 아니며
기존 라우팅과 공급자 설정에 따라 바뀐다. 고객 원문은 검수에 사용하지 않았다.

## 실행·정리

접수 후 기존 AI 큐에서 처리하며 n8n이 Raya를 호출할 때 부모 연산 토큰을 이어받아
다시 최상위 슬롯을 기다리는 교착을 피한다. n8n 응답은 60초 제한이고 잘못된 결과는 실패다.
실행 중 취소는 n8n 내부 요청 중단을 보장하지 않으며 늦은 결과를 저장하지 않는다.

원문과 번역문은 AI DB 결과이며 임시 파일·영속 NAS 파일을 추가하지 않는다.
웹 24시간·플랫폼 기본 7일 후 접근을 차단하고 정기 정리에서 prompt·input·result를 비운다.
이력·사용량은 남긴다. 만료 ID로 새 실행을 요청하지 말고 새 request_id를 사용한다.
플랫폼은 notify:true로 별도 AI 완료 웹훅·receipt를 선택한다. 파일 Job 이벤트와 구분한다.
AI 수신 URL은 플랫폼 수신기 구현 후 암호화 설정에 넣는다. 미설정 접수는 503이다.
